## 문서

|---|---|---|

| [docs/premortem/양진석.md](docs/premortem/양진석.md) | 양진석 개인 프리모텀 | 본인 계정으로 커밋 |
| `docs/premortem/각자이름.md` | 나머지 팀원 개인 프리모텀 | 각자 본인 계정으로 추가 필요 |
| `docs/PREMORTEM.md` | 팀 종합 프리모텀 | 모든 개인 파일 이후 저장소 소유자가 커밋 예정 |

## 팀원이 개인 파일을 올리는 방법

1. **본인 GitHub 계정**으로 로그인합니다.
2. 이 저장소를 열어 **Fork**를 눌러 본인 계정으로 복사합니다.
3. 복사된 저장소에서 **Add file → Create new file**을 선택합니다.
4. 파일 이름에 `docs/premortem/본인이름.md`를 입력하고 본인이 작성한 내용을 넣습니다.
5. **Commit changes**로 저장합니다. 이때 커밋 작성자는 로그인한 본인 계정이어야 합니다.
6. **Contribute → Open pull request**로 이 저장소의 `main` 브랜치에 반영 요청을 보냅니다.
7. 저장소 소유자가 내용을 확인하고 반영합니다. 개별 작성자 커밋을 유지하도록 merge commit 방식으로 병합합니다.

팀원 전원의 개인 파일이 반영된 뒤, 팀이 함께 정리한 `docs/PREMORTEM.md`를 저장소 소유자가 커밋합니다. 다른 사람의 파일을 소유자 계정에서 대신 작성·커밋하면 본인 계정 커밋 조건을 충족하지 못합니다.

## 공개 전 확인

- 상담 이후 실제로 수정한 내용을 사용하고, 미확정 사항은 미확정으로 표시합니다.
- 연락처, 동의받지 않은 팀원의 개인 정보, 회사·고객의 기밀을 제외합니다.
- 비밀번호, API 키, `.env` 파일은 올리지 않습니다.
