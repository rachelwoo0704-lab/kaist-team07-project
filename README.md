## What we are building

마신 와인의 기록을 바탕으로 자신의 취향을 알아가고, 다음 와인을 선택하는 데 도움을 주는 서비스를 기획하고 있습니다.

와인을 마신 경험이 사진이나 막연한 인상으로만 남아 다음 선택에 활용되지 않는 문제에 주목합니다. 국내에서 실제로 구매할 수 있는 와인을 중심으로, 익숙하지 않은 전문 용어를 따로 공부하지 않아도 자신의 경험과 취향을 연결할 수 있는 방향을 검토하고 있습니다.

## Who it is for

와인에 관심은 있지만 혼자 와인을 고르기는 어려운 국내 와인 초보를 대상으로 합니다.

- 이전에 맛있게 마신 와인의 이름이나 좋았던 이유가 잘 기억나지 않는 사람
- 와인의 맛을 설명하는 표현이 낯설어 자신의 취향을 말하기 어려운 사람
- 매장에서 와인을 고를 때 가격이나 점원의 추천에 주로 의존하는 사람

## Current status

현재는 서비스 기획 단계입니다. 교수님 상담 이후, 팀 내에서 주제 변경 가능성과 구체적인 대안을 논의하고 있습니다. 새로운 주제는 아직 확정되지 않았습니다.

아래 문서는 현재의 **Wine not?** 기획을 기준으로 작성한 자료입니다. 향후 방향이 확정되면 프로젝트 기획, 질문, 프리모텀과 수정 이력을 함께 갱신할 예정입니다.

### 남은 작업 순서

1. 팀이 상담 피드백과 실제 변경 결정을 정리합니다. [QUESTIONS.md](docs/QUESTIONS.md)의 **After the consultation** 표에 들은 내용·할 일·담당자·기한을 기록하고, 관련 문서와 **Revision log**를 갱신합니다.
2. 우승현이 자신의 GitHub 계정으로 [개인 프리모텀](docs/premortem/Premortem_우승현.md)을 검토·수정하고 커밋합니다. 파일의 독립 작성 여부 `[yes / no]`도 본인이 확인해 채웁니다.
3. 모든 개인 커밋이 팀 저장소에 반영된 뒤, 소유자 양진석이 [종합 프리모텀](docs/PREMORTEM.md)을 검토·수정하고 자신의 계정으로 커밋합니다.
4. 이 체크리스트를 실제 완료 상태에 맞게 갱신합니다.

직접 수정 권한이 있으면 팀 저장소에서 커밋할 수 있습니다. 권한이 없으면 본인 계정으로 Fork → 개인 파일 수정·커밋 → 팀 저장소에 PR을 보내고, 소유자가 작성자 이력을 유지해 병합하면 됩니다. 소유자가 대신 업로드한 파일은 해당 팀원의 본인 계정 커밋을 대신하지 않습니다.
